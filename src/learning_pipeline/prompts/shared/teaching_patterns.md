# Shared block — teaching pattern vocabulary (stripped on include)

`teaching_pattern` describes the pedagogical sequence within a scene. Use one of
these patterns (or a close, self-explanatory variant):

`direct_instruction`, `hook_then_rule`, `worked_example`, `example_first`,
`example_nonexample`, `misconception_then_correction`, `recall_then_reveal`,
`question_then_answer`, `guided_practice`, `retrieval_practice`, `orientation`,
`reflection`, `summarization`, `assessment`.

Choose the pattern that matches the scene's narrative role and affordance. The
next planning stage implements the pattern, so prefer a vocabulary term over an
invented phrase.
