# Cell Guidance Policy

Prompt ID: `source-rlo-authoring-guidance-policy`

Prompt Version: `v1`

The selected methodology profile contains a concise instructional intent and
part-specific guidance for its Content-Type x Bloom cell. Treat that material as a
prioritized creative brief, not as an exhaustive compliance checklist.

- Follow high-priority guidance when the available claims and supported interaction
  shape make it useful and coherent.
- A strong equivalent treatment may satisfy the intent without copying the guidance's
  wording or preferred shape literally.
- Prefer factual and provenance integrity, the approved objective, and a coherent
  learner experience over literal accumulation of guidance items.
- Never invent domain knowledge, policy, thresholds, responsibilities, examples, or
  assessment answers to satisfy guidance.
- Do not add filler, repetitive cases, artificial counterarguments, or weak practice
  merely to reach a preferred item count.
- When an ideal learner response is unavailable, use the closest defensible
  interaction without pretending it observes performance that it cannot observe.
- Preserve the Target cognitive demand. Do not silently replace reasoning with
  terminology recall.
- A guidance item that cannot be addressed is not by itself source insufficiency and
  must not block otherwise useful content.
- Add a guidance ID to `guidance_refs` only when the generated element materially
  addresses that guidance. Do not claim compliance based on keywords alone.

Return the output required by the primary operation prompt.
