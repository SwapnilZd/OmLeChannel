Brand assets for the web interface belong in this directory.

Use web-safe SVG, PNG, or WebP files with transparent backgrounds. Keep source
artwork outside the Docker image and add only the optimized display asset here.
Suggested names:

- deloitte-logo.svg
- product-mark.svg
- login-illustration.webp

The interface uses `deloitte-logo-web.png`, an optimized display crop derived
from the approved `Deloitte-Master-Logo-Alpha.png` source asset in this folder.
